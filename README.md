# Reviewer Instructions

Dear Reviewers,

Thank you very much for taking the time to review our work. Below is a brief description of the contents of this folder to help you navigate and evaluate our experiment.

## Folder Contents

### Experiment Demonstration Files
   These files contain the experimental results presented in an interactive format:

   - **please_click_me.html**  
     This is the homepage of the project. By opening the `index.html` file in a browser, you can view the main experimental results and demonstrations.

   - **css/**  
     This folder contains the CSS files used for styling the homepage.

   - **images/**  
     This folder includes the image assets used in the html, such as visual examples displayed on the homepage.

   - **jquery/**  
     This folder contains the JavaScript libraries (specifically jQuery) used to add interactive functionality to the homepage.

   - **videos/**  
     This folder stores video assets that are part of the experimental demonstration, showcasing dynamic results or animations.

## Usage Instructions

To view the experiment, simply open the `index.html` file in your web browser. Thank you.
