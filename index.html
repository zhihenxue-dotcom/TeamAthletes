TeamAthletes

Part-Refined and Number-Arbitrary Human Interactive Generation via Iterative Retrieval Augmentation

Task Introduction

In our work, we focus on achieving precise generation of all body part movements for every individual motion in complex multi-person interaction scenarios. We conduct a retrieve-then-interact paradigm that leverages multi-level textual prompts—particularly detailed descriptions of body parts, to generate motions that are highly aligned with the input text.

TeamAthletes Framework

We propose TeamAthletes, a unified framework that enables fine-grained controllable motion generation upon arbitrary-scale group interaction, following a retrieve-then-interact paradigm. In the initial iteration, we directly utilize body part features retrieved in Body-part Enhanced Retriever to guide the generation branch. In the follow-up iterations, retrieved features will interact with motions from initial iterations in Multi-granularity Guided Interactor, finally forming the guidance for generation branch.
